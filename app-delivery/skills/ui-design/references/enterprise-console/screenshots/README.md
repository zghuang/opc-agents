# Enterprise Console Screenshots

Place screenshots of approved internal systems here. Recommended set:

- `dashboard.png`: default landing workspace or overview.
- `list.png`: table/list page with filters and actions.
- `form.png`: create/edit form.
- `detail.png`: record detail or approval page.

The skill uses these as style/layout references, not strict pixel specs unless explicitly requested.

If only the bundled logo is present, use `../notes.md` for the text reference. The intended enterprise baseline is a restrained internal console with solid Merck-compatible colors, dense but readable tables/forms, clear navigation, and complete feedback states.
